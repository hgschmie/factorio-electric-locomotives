# Electric Locomotives

Adds electric trains to Factorio. This started out as an attempt to fix the various electric train mods that exist but became a full rewrite.

Electric trains are an alternative to the regular Factorio Locomotives. They do not need to be refueled but are controlled and powered by control stations that need to be placed on the same surface as the trains. A control station only supports trains on the same surface. Control stations directly connect to the power grid and send power directly to the locomotives.

Three tiers of electric locomotives exist:

|    Tier   |Consumption|         Speed           |
|-----------|-----------|-------------------------|
| Standard  | 600 KW    | 259.2 kph maximum speed |
| MK2       | 900 KW    | 388.8 kph maximum speed |
| MK3       | 1.2 MW    | 518.4 kph maximum speed |
